## Milestone 1

### Description
Speed runners are a niche yet very active group. For the unaware, speedrunning refers to a person or persons trying to complete a video game as fast as possible. This database exists to catalogue and record people’s playthroughs and records in order for them to compare their respective goals and progress. It will host details such as the games played, platforms played on, last date played, whether the game was emulated or not, and more!

### Data Acquisition
Data Acquisition: Our data will be coming from https://www.speedrun.com/. This website exists for much the same purpose as our database, and as such, shares much of the same data. With this data already compiled and updated for us, we will populate our final database with data selected from there. For milestone 1, we will make up sample data to ensure database functionality without spending too much time worrying about the data itself. 

### Assumptions
Because this database on https://www.speedrun.com/ already exists, much of our assumptions have been made for us. Our main assumption is that the user knows how to use the database and is familiar with the kind of data stored. Because this database’s function is so niche, it could be reasonably assumed that users visiting or uploading to the database would be somewhat familiar with its purpose.
